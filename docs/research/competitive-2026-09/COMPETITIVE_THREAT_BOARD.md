## 0. How to read a kill

A threat kills Mcfly by winning **one** of these races:

| Race | Clock | Mcfly is dead if… |
| --- | --- | --- |
| **Discovery** | 30 days | Merchants who want this job never see Mcfly, or see it next to Free and bounce |
| **Substitution** | 30–90 days | The merchant already has a “good enough” answer (Sheet, Admin, Kleio, TP) |
| **Habit** | 90–365 days | A daily/weekly ritual lives in someone else’s product |
| **Wallet** | 30–90 days | The $35–$49 profit budget is spent |
| **Definition** | 365 days | Shopify itself ingests spend + costs, or Kleio/TP become the default noun |

**Cope** = a Mcfly line that sounds sharp and does not change the race.  
**Real counter** = a change that can be observed (listing cluster, TTV, a wedge they structurally refuse).

Mcfly live control: https://apps.shopify.com/mcfly-analytics-public — **$39 / 7-day / 0 reviews / launched 2026-09-07 / paste CSV / no Works-with / Clarity–WeTracked–Parkour rail.**

## 9. What would have to be true for Mcfly to still exist in 365 days

All of these are **conditions**, not promises.

1. **A computed-week habit exists for a named cohort** (P1 or P3). MASTER_PLAN already kills if they won’t open weekly.  
2. **Either** App Store reviews exist **or** outbound revenue exists. Not neither (`RELIGION_FLEX.md` R11).  
3. **A wedge Kleio and TP structurally under-weight:** billboards/retainers as first-class, claims-vs-cash as a card, flat no-surcharge, Monday artifact. Religion-only is not a wedge — Kleio has the religion.  
4. **Ease is not paste-only.** Public evidence: every loved paid desk syncs spend.  
5. **Shopify still does not ingest third-party spend.** If they do, Mcfly must already be the **definition / overlay** layer (S4) or it is a feature.  
6. **Listing integrity.** False LTV/Goals and “mailto” will not survive the first skeptical merchant.

`SYNTHESIS.md` default if money+love+ease+real: **S1 + S5b + 14-day + listing integrity**, add S2 pieces only with a wedge. This board is why.
